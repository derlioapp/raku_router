The authoritative changelog ships with the package:

- **[CHANGELOG on pub.dev](https://pub.dev/packages/raku_router/changelog)** — the
  released history.
- **[CHANGELOG on GitHub](https://github.com/derlioapp/raku_router/blob/main/CHANGELOG.md)**
  — the same history, in the repo.

raku_router follows [semantic versioning](https://semver.org/). Pre-`1.0`, a
breaking change ships in a minor bump with a migration note in the changelog; the
API has had its 1.0 freeze review, so what remains is field validation, not
churn.
